## What it does

`main.py` (Python standard library only) writes one sentence — at most 200
characters — pitching a bizarre startup idea that sounds ridiculous at first
glance yet is clearly a real business, to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output/entry.txt`).

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

The output is deterministic: the same sentence, byte for byte, on every run.
